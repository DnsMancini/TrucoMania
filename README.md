# TrucoMania

Estrutura inicial do projeto TrucoMania com backend em Node.js + Socket.IO e frontend estático.

## Como rodar

```bash
npm install
npm start
```

Abra em: `http://localhost:3000`

## Estrutura

- `index.js`: ponto de entrada do servidor.
- `server/`: aplicação, lógica do jogo e sockets.
- `client/`: interface web simples do jogo.
